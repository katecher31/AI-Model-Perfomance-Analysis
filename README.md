# AI Model Performance Analysis

Statistical analysis of response time and performance characteristics across four open-source vision-language models.

## Project Overview

This project is being completed as part of the Probability and Statistics for AI course in the M.S. in Applied Artificial Intelligence program at the University of San Diego.

The project analyzes benchmark data from four open-source vision-language models and investigates how response time varies across models and request characteristics.

## Research Question

How does response time vary across models and request characteristics, and what does that imply for model selection in a multi-model workflow?

## Dataset

The dataset contains approximately 600 benchmark runs across four open-source vision-language models, including text, image, and mixed-input requests.

Variables include model information, request characteristics, response time, CPU and GPU utilization, memory usage, and throughput.
